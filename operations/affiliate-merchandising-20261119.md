# 2026-11-19: 購入導線と商品分類の追加改善

既存の楽天API取得、価格履歴、Affiliate ID暫定継続、週次noteの仕様を
変更しない、サイト生成時の**表示改善**。

## 商品分類

既存の楽天商品情報には次のような紛れ込みが見られる。

- Qi2充電器のための通常ACアダプター（店の商品名で別商品の
  「当社Qi2ワイヤレス充電器に最適」を参照するため、Qi2検索にヒット）
- 「Macaroon SE 専用 モバイルルーター ケース」のような
  モバイルルーター本体ではないアクセサリ

`scripts/affiliate_quality.py` の `displayable()` で明確な例を追加除外する。
分類は**閲覧時のみ**で、`scripts/fetch_rakuten.py` の取得候補・
過去価格履歴・Windows収集下限を変更しない。
説明だけで製品の仕様を断定せず、正規のセット商品は残す。

## 購入導線

- 商品タイトルからも、楽天APIが返したままの公式アフィリエイトURLへ移動。
- 商品画像リンクは、読み上げ環境で目的が分かるよう商品名付き。
- 既存の購入ボタンはそのまま維持。
- 同一商品に「画像」「タイトル」「ボタン」の3つの導線がある。
  いずれも `rel="sponsored nofollow noopener"` と `target="_blank"`。
- GA4が有効なときのみ `affiliate_click` に
  `category-card:image/title/button` 等の掲載位置を付与。
  測定IDが未設定の場合はクリック計測を**無効のまま**にする。
- テキストリンクのマウスホバー・キーボードフォーカスを明確にする。

## 受け入れ条件

```
python -X utf8 -m unittest discover -s scripts -p "test_*.py" -v
```

実際の楽天APIリクエスト、note.com投稿、Windowsタスク再登録、
Affiliate ID確認記録変更は一切行わない。

次の正常な公開で生成されたHTMLにのみ反映される。WindowsローカルPCで
旧コミットに固定されている場合、ローカルの配置状態は別途確認する。
これをオフラインCI成功だけで「本番サイトに反映済み」としない。
